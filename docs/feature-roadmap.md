# SmartPantry Feature Roadmap

## Strong MVP features already suitable for defense

- Local authentication
- User profile with personalization
- Bilingual interface: English / Russian
- Visual food inventory
- Expiration-first prioritization
- Rule-based AI assistant chat
- Recipe suggestions with time and calories
- Analytics for active, expiring, used, and wasted products
- Local expiration notifications via WorkManager
- Anti-waste score
- Smart shopping suggestions
- Research-driven positioning based on Lab 1, Lab 2, and Lab 3

## High-value next features for presentation

### 1. Smart expiration notifications

- Local notifications 2-3 days before expiration
- Evening reminder based on user reminder hour
- Separate reminder for leftovers

Why it is strong:
- directly solves the forgetfulness problem from user research
- easy to explain and highly practical

### 2. Auto shopping suggestions

- Detect low-stock or missing staples
- Suggest shopping list items based on usage patterns

Why it is strong:
- reduces planning effort
- expands the system from tracking to decision support

### 3. Real AI API mode

- Connect assistant to OpenAI when API key is available
- Keep local rule-based fallback when offline or key is missing

Why it is strong:
- makes the “AI assistant” criterion fully demonstrable
- preserves MVP stability

### 4. Receipt or barcode scanning

- Add items faster using barcode scanning
- Optional OCR from receipt photo

Why it is strong:
- reduces manual input
- aligns with usability findings from research

### 5. Weekly anti-waste score

- Score based on used vs wasted items
- Show trend improvement week to week

Why it is strong:
- useful for analytics and defense
- links directly to measurable behavioral impact

### 6. Leftover mode

- Special section for cooked food and leftovers
- Prioritize them in recipes and reminders

Why it is strong:
- one of the most realistic household waste sources
- easy to explain with user stories

## Best defense angle

Frame SmartPantry as:

"A cognitive support system for household food management."

That wording is academically strong because it connects:

- user research
- information systems theory
- measurable practical value
